# Bonzai Hermes Plugin

The README documents the provider, installer, Key Manager backend and companion extension. Core Hermes Desktop source changes are separate and must be published from the Hermes repository.

## Working rules

- Keep provider, installer, key-manager, and desktop-plugin behavior compatible with Hermes Desktop.
- Never expose API keys or copy secrets into source, logs, commits, or documentation.
- Use the repository's Python environment and test scripts where applicable.
- Check the existing README and repository conventions before changing installation or configuration behavior.
- Preserve existing local changes unless the user explicitly asks to discard them.

## Installation and testing

The README documents end-user install, upgrade, check, troubleshooting and uninstall commands. Run the Python and JavaScript behavior tests with:

```bash
uv run --with-requirements requirements-test.txt --python 3.11 pytest -q
node --check key-manager/desktop/plugin.js
node --check tests/js/run_plugin.mjs
python3 -m py_compile bonzai/__init__.py install.py key-manager/dashboard/plugin_api.py
git diff --check
```

Before proposing a GitHub update, inspect the complete diff, run the entire pytest suite, and check for secrets. Do not publish until both documentation and manifest version match the behavior. The provider version is 2.10.0; Key Manager UI/backend version stays 2.0.0 because only provider code and internal routing fixes have changed. Preserve pre-existing local edits unless explicitly asked otherwise.
